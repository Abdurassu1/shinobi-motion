# Shinobi Motion

**Camera-Powered Jutsu Training · ADMIT HACKATHON**

## Overview

Браузерная тренировка шиноби с управлением камерой. Техники упрощены до одного комфортного движения: можно играть сидя, не выпрямлять локти и не напрягать ладони. После стартового нажатия этапы переключаются автоматически.

## Features

- Реальные landmarks MediaPipe Pose Landmarker и собственные правила четырёх техник.
- Простые движения, широкие допуски, короткое подтверждение 250 мс.
- Калибровка по двум плечам за 600 мс; бёдра и локти не обязаны попадать в кадр.
- Подсветка нужной руки, направляющие стрелки, конкретные подсказки.
- Четыре эффекта Canvas, звук (свои файлы из public/audio/ или встроенный синтез Web Audio как запасной вариант), mute, reduced motion.
- Очки, результат, ранг, повтор и отдельное явно подписанное демо.
- Обработка локально: без записей, отправки кадров, backend и аккаунтов.

## How It Works

1. Нажмите BEGIN TRAINING и разрешите камеру. Микрофон не используется.
2. Сядьте или встаньте удобно: в кадре достаточно обоих плеч и руки, которой выполняете жест.
3. Калибровка займёт 0,6 секунды устойчивого отслеживания.
4. Сделайте одно движение по картинке и ненадолго остановитесь — на 0,25 секунды.
5. Эффект, +100 и переход к следующей технике происходят автоматически.
6. После четырёх техник появляется MISSION COMPLETE, камера останавливается.

Левая и правая руки указаны относительно вашего тела. Изображение зеркальное. Достаточно спокойного движения; пальцы и направление ладоней значения не имеют.

## Gesture Recognition

Основной режим получает реальные кадры через getUserMedia и передаёт их в Pose Landmarker. Распознавание использует координаты плеч и запястий. Отдельная модель кистей больше не нужна и не загружается.

Результат содержит gesture, confidence, valid и error с кодом, инструкцией, суставами и направлением исправления. Confidence — минимальная видимость необходимых суставов, а не вероятность правильности jutsu.

## Error Mode

| Ситуация                                     | Подсказка                               |
| -------------------------------------------- | --------------------------------------- |
| Человека или плеч не видно                   | Посмотреть в камеру, показать оба плеча |
| Слишком далеко/близко                        | Немного приблизиться/отодвинуться       |
| Активная кисть вне кадра                     | Показать нужную руку                    |
| Нужная рука ещё опущена                      | Поднять её до груди                     |
| При одноручной технике поднята и другая рука | Расслабить свободную руку и опустить    |
| Katon: руки далеко                           | Свести руки перед грудью                |
| Shadow clone: руки низко или вместе          | Поднять до плеч или слегка развести     |

Подсвечивается конкретная рука; стрелки показывают направление исправления. Свободная рука у одноручных техник может находиться вне кадра. Не требуется показывать бёдра или строго выравнивать руки.

Первые 3 секунды техники даются на знакомство. Затем непрерывная ошибка формы в течение 1,2 секунды считается одной ошибкой (−10), а не списанием на каждом кадре. Повторная попытка переоткрывается после 350 мс правильной формы. Потеря человека, нужной руки или видеопотока не штрафуется.

## Custom Recognition Logic

Собственные правила находятся в src/vision/gestureRules.ts. MediaPipe используется только как источник landmarks.

- Масштаб — ширина плеч. Высота кисти относительно плеч делится на ширину плеч и aspect ratio кадра.
- Достаточная видимость ключевых точек: 0,60. Допустимая ширина плеч в изображении: 0,12–0,72.
- Rasengan: правая кисть не ниже 0,55 ширины плеч от линии плеч. Если свободная левая кисть видна, она должна быть ниже 0,65.
- Chidori: зеркальное правило для левой руки. Глубина и угол локтя не проверяются.
- Katon: обе кисти не ниже 1 ширины плеч, расстояние между ними не больше 0,65. Можно держать их вместе или с небольшим зазором.
- Shadow clone: обе кисти не ниже 0,35 ширины плеч, горизонтальное расстояние между ними от 0,85. Точная симметрия не требуется.
- Удержание 250 мс подтверждается последовательными реальными наблюдениями. Неверный кадр, низкая уверенность, пропуск более 300 мс или непоследовательный timestamp сбрасывают прогресс.
- На время эффекта повторные срабатывания заблокированы. Предыдущая поза не завершает следующую технику.

Это проверка простых целевых положений после движения, а не оценка скорости или траектории взмаха. Быстро махать не нужно.

## Jutsu

| Техника      | Одно движение                     | Эффект                                             |
| ------------ | --------------------------------- | -------------------------------------------------- |
| Rasengan     | Приподнять правую руку к груди    | Сфера у правой кисти, кольца и энергетический звук |
| Chidori      | Приподнять левую руку к груди     | Молнии у левой кисти и электрический треск         |
| Katon        | Свести руки перед грудью          | Растущий огненный шар, поток пламени, ударная волна и тёплое затемнение экрана |
| Shadow clone | Поднять обе руки по бокам до плеч | Четыре живые копии с видеопотока (синий тинт) появляются по очереди вокруг игрока, каждая с кольцом у головы и облаком дыма |

Эффект с подготовкой и начислением очков длится 2,4 секунды. Reduced motion убирает тряску, активные частицы и декоративные анимации.

Счёт: max(0, mastered × 100 − mistakes × 10), максимум 400. Accuracy — доля корректных кадров среди оцениваемых кадров формы после периода знакомства. Отсутствие человека исключается; без оценённых кадров отображается 100%. Ранг: 0 ошибок — JONIN, 1–4 — CHUNIN, больше — GENIN.

## Tech Stack

React 19, TypeScript, Vite 8, MediaPipe Tasks Vision 1.0.1, Canvas 2D, Web Audio API, CSS и Vitest. Space Grotesk и IBM Plex Mono обслуживаются локально через Fontsource.

## Architecture

```text
src/App.tsx                       — главная страница и переключение режима
src/components/TrainingSession.tsx — камера, цикл, обучение и результат
src/components/GesturePreview.tsx  — SVG-примеры простых движений
src/vision/camera.ts               — доступ к камере и освобождение треков
src/vision/landmarks.ts            — Pose Landmarker
src/vision/gestureRules.ts         — собственная геометрия жестов
src/vision/gestureDetector.ts      — подтверждение по нескольким кадрам
src/vision/errorEngine.ts          — структурированные подсказки
src/vision/demo.ts                 — только явно синтетические демо-входы
src/game/                         — этапы, инструкции и счёт
src/effects/renderer.ts            — skeleton, стрелки и эффекты
src/audio/soundManager.ts          — оригинальные процедурные звуки
scripts/setup-vision.mjs           — установка модели и WASM
public/vision/                    — локальные assets
```

Поток: Camera → Landmarks → Custom rules → Error feedback → Temporal confirmation → Training state → UI/effects/audio.

Inference работает отдельно от React render, в requestAnimationFrame с ограничением до 20 измерений/с и шириной входного кадра 640 px. React обновляется примерно 10 раз/с. Для рисунка точки сглаживаются, для распознавания используются исходные измерения. При скрытии вкладки удержание сбрасывается. При остановке кадров прогресс сбрасывается; через 8 секунд появляется ошибка. Выход, перезапуск, ошибка и завершение освобождают камеру и модели.

## Installation

Для разработки нужен Node.js 22.12+ и npm. Игрокам опубликованного сайта нужен только браузер.

```bash
npm install
```

Postinstall копирует WASM из закреплённой версии пакета и загружает официальную модель Pose Landmarker Lite. Интернет нужен для установки. Уже скачанная модель используется повторно. Если загрузка прервалась:

```bash
npm run setup:vision
```

## Running Locally

```bash
npm run dev
```

Откройте адрес Vite, http://localhost:5173.
